# 🩺 MediAI Assistant

## AI-Powered Medical Information Chatbot

MediAI Assistant is an AI-powered medical information chatbot built with Python, Streamlit, and the Groq API.

It provides general health and medical information through a simple conversational interface.

## ✨ Features

- 🤖 AI-powered medical assistant
- 💬 Conversational chat
- 🧠 Conversation history
- 🎨 Streamlit web interface
- 🔐 Secure API key management
- ⚠️ Medical safety disclaimer
- 🗑️ Clear conversation option
- 📱 User-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Large Language Model (LLM)
